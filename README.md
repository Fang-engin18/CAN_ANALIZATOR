# CAN_ANALIZATOR
Данный CAN-анализатор создан под грантовский проект для анализа машин/с/х машин и т.д. Здесь выложена наработка для обработки одной high speed can-шины. Т.е не рабочая версия в полном понимание обработки полного комплекса датчиков установленных на технике, а только ее ограниченная часть. Ею обрабатывать 2 и более шины нельзя, также и low-speed шину. 

Работает: OBD2->трансивер->MCP2515->STM32
Но для эксперимента проверки одной шины можно использовать.
