#CAN Analyzer. Файл(CAN_work.rar)
Компактный трёхканальный CAN-анализатор для диагностики и мониторинга бортовых сетей сельскохозяйственной и транспортной техники.
Устройство построено на базе микроконтроллера STM32G473VET6 со встроенными контроллерами FDCAN. В отличие от архитектур с внешними CAN-контроллерами, обработка CAN-кадров выполняется непосредственно микроконтроллером: после физического уровня сигнал поступает с CAN-трансивера напрямую на встроенный FDCAN-контроллер STM32.
Проект включает разработку принципиальной схемы, печатной платы, системы питания, трёх независимых CAN-интерфейсов и беспроводного интерфейса передачи данных.

##Основная особенность проекта — отказ от внешних CAN-контроллеров.

Вместо распространённой схемы:

             ┌── SN65HVD230 ──► FDCAN1 ──┐
CAN Channel 1┤                            │
             ├── SN65HVD230 ──► FDCAN2 ──┤
CAN Channel 2┤                            ├──► STM32G473VET6
             ├── SN65HVD230 ──► FDCAN3 ──┤

                             UART
                              │
                              ▼
                         Bluetooth
                              │

Таким образом, CAN-трансивер отвечает только за физический уровень, а обработка CAN-кадров выполняется встроенными FDCAN-контроллерами STM32G473.

Это позволяет уменьшить количество компонентов, упростить трассировку PCB и реализовать одновременную работу трёх CAN-каналов на одном микроконтроллере.

##CAN-интерфейсы;
Каждый из трёх каналов имеет собственный CAN-трансивер SN65HVD230.

CANH ──┐
       │
       ▼
  ┌───────────┐
  │ SN65HVD230│
  └─────┬─────┘
        │
        ├── TXD
        └── RXD
             │
             ▼
        STM32G473
           FDCAN

На физическом уровне предусмотрены:

фильтрация высокочастотных помех;
TVS-защита;
согласование CAN-линии;
split termination;
последовательные резисторы на цифровых линиях.

Для защиты CAN-линий используется специализированный TVS-элемент PESD1CAN.

Согласование реализовано посредством split termination:

CANH ─── 60 Ω ───┬─── 60 Ω ─── CANL
                  │
                 100 nF
                  │
                 VREF

Суммарное сопротивление терминации составляет:

R = 60 Ω + 60 Ω = 120 Ω

Split termination также используется для снижения синфазных высокочастотных помех.

##Design Approach

При проектировании платы основное внимание уделялось:

* минимизации количества внешних компонентов;
* разделению функциональных зон;
* снижению влияния импульсного преобразователя на цифровую часть;
* защите CAN-интерфейсов;
* целостности CAN-сигналов;
* компактности конструкции;
* возможности дальнейшего расширения устройства.

Ключевым архитектурным решением стало использование встроенных FDCAN STM32G473 вместо внешних CAN-контроллеров.

Это позволило построить трёхканальный CAN-анализатор без MCP2515 и аналогичных внешних контроллеров.

## Описание проекта

Данный CAN-анализатор разработан в рамках грантового проекта, посвящённого исследованию и анализу данных, передаваемых по CAN-шине автомобильной и сельскохозяйственной техники.

Проект представляет собой экспериментальную аппаратно-программную платформу для приёма и обработки сообщений одной High-Speed CAN-шины. Текущая версия является демонстрационной наработкой и предназначена для изучения принципов работы CAN-сетей, тестирования оборудования и проведения исследовательских экспериментов.

Важно понимать, что данный репозиторий не содержит полноценную реализацию комплекса мониторинга техники и не предназначен для одновременной работы с несколькими CAN-сегментами. Поддерживается только одна High-Speed CAN-шина.

### Ограничения текущей версии

* Поддержка только одной High-Speed CAN-шины.
* Отсутствует поддержка Low-Speed CAN.
* Невозможна одновременная работа с двумя и более CAN-шинами.
* Реализована ограниченная часть функциональности, используемой в полном грантовом проекте.
* Предназначен преимущественно для исследований, экспериментов и отладки.

### Текущий статус

Работоспособность подтверждена для приёма и обработки сообщений одной High-Speed CAN-шины через интерфейс OBD-II.

Проект может использоваться для:

* изучения протокола CAN;
* анализа CAN-трафика;
* тестирования отдельных узлов техники;
* отладки CAN-устройств;
* образовательных и исследовательских целей.

Для построения полноценной системы мониторинга техники требуется дальнейшее развитие аппаратной и программной частей проекта.

### Принципиальная схема

Принципиальная схема устройства CAN-анализатора. Реализована аппаратная цепочка OBD-II → CAN-трансивер → MCP2515 → и по uart на STM32, обеспечивающая приём, обработку и передачу CAN-сообщений для последующего анализа.
